## 💧 Overview
This project predicts whether a given water sample is **safe to drink** using an AI-powered Feedforward Neural Network (FNN).  
It combines **Flask**, **TensorFlow**, and **WHO water safety standards** to make real-time, reliable predictions with a user-friendly web interface.

---

## ⚙️ Features
- 🤖 **AI-Based Prediction** using TensorFlow/Keras  
- ✅ **WHO-Standard Validation** for water safety  
- 💻 **Flask Web Application** with real-time input  
- 🎨 **Modern, Responsive UI** built with HTML, CSS, and JS  
- 📊 **Fast, Accurate Results** displayed instantly
